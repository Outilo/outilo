# Contribuer

Outilo est open source sous licence **Apache-2.0**. Pendant la V1, le développement est mené par l'équipe et les
extensions publiées sont uniquement les extensions officielles.

## Améliorer cette documentation

Le site vit dans le dossier `site/` du dépôt `outilo` (Nextra).

```bash
cd site
npm install
npm run dev     # http://localhost:3000
npm run build   # export statique dans out/
```

Chaque page est un fichier `app/docs/**/page.mdx` ; l'ordre du menu est défini par les fichiers `_meta.js`.

## Signaler un problème

Ouvrez un ticket sur [github.com/outilo/outilo/issues](https://github.com/outilo/outilo/issues).
