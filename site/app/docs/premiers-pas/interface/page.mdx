# L'interface

Outilo reprend les codes d'un éditeur de code : on y passe vite d'un outil à l'autre, au clavier.

```text
┌───────────────────────── Barre de titre · palette (Ctrl K) ─────────────────────────┐
│ ▣ │ Explorateur        │ [Accueil] [Mots de passe ×] [Utilisateurs ×]                │
│ ⚒ │  Favoris           │                                                              │
│ ⊞ │  Extensions        │                 Contenu de l'outil actif                      │
│ ◐ │  Catégories        │                                                              │
├───┴────────────────────┴──────────────────────────────────────────────────────────────┤
│ Barre d'état : hors-ligne · extensions · mises à jour · langue                         │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

| Zone | Rôle |
| --- | --- |
| Barre d'activité | Accueil, outils, extensions, thèmes, paramètres |
| Explorateur | Favoris, extensions installées, catégories |
| Onglets | Plusieurs outils ouverts en même temps, état conservé pendant la session |
| Barre d'état | État réseau, nombre d'extensions, mises à jour disponibles, langue |

## Raccourcis

| Raccourci | Action |
| --- | --- |
| `Ctrl K` | Palette de commandes : outils, actions rapides, commandes des extensions |
| `Ctrl W` | Fermer l'onglet |
| `Ctrl Tab` | Onglet suivant |
| `Ctrl ,` | Paramètres |
| `Alt Maj Espace` | Ouvrir la palette depuis n'importe où (**optionnel**, désactivé par défaut) |

## Langues

Français et anglais, modifiable dans **Paramètres → Langue**. Les extensions fournissent leurs propres traductions.
