# Profils

Au premier lancement, vous choisissez un ou plusieurs profils. Chacun correspond à un **pack d'extensions**
installé automatiquement. Vous pourrez toujours en ajouter ou en retirer.

| Profil | Extensions installées |
| --- | --- |
| Développeur | Mots de passe, Utilisateurs fictifs, JSON, JWT, Encodeurs, Hash, UUID, Regex, Timestamps, Ports & processus |
| Webdesigner | Couleurs, Lorem ipsum, QR code, Mots de passe |
| DevOps / admin | Ports & processus, Réseau, Hash, Cron, Infos système, Nettoyeur |
| Usage quotidien | Nettoyeur, Mots de passe, QR code, Infos système |
| Personnalisé | Choix libre |

Les packs sont définis dans le registre : ils évoluent sans mise à jour de l'application.

Le profil choisi est conservé. À terme, il servira à adapter l'interface à votre métier (accueil, raccourcis,
disposition).
